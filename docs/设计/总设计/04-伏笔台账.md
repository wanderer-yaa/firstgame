# 04 · 伏笔台账

> 版本：v2.0　更新：2026-10-24
> 用途：**长线叙事**——所有伏笔的唯一事实源。设计、文案、系统三方共用。

---

## 0. 怎么用

- 每埋一个伏笔先登记，回收后改状态
- 状态：`待埋` / `已埋` / `待回收` / `已回收` / `废弃`
- 每次写新内容前查一遍，避免重复埋、也避免漏埋
- **不在这张表里的伏笔，不算伏笔**

---

## 1. 三条原则

**① 每条伏笔至少要有 2–3 种说得通的假说。**

只有一种解释的叫预告，不叫伏笔。玩家应该能猜错两次——猜错的过程才是好奇心的来源。这也是"传说不可证实"能被接受的前提：**不可证实 ≠ 无迹可寻**，每条传说至少要给玩家两个可观察的线索。

**② 回收优先级：使用 > 遭遇 > 揭示。**

| 方式 | 说明 | 爽感 |
|---|---|---|
| **使用** | 玩家自己用上了前期埋的东西 | 最高 |
| **遭遇** | 玩家亲眼看到真相 | 中 |
| **揭示** | NPC 告诉你 | 最低，但最省 |

**③ 密度：每个境界最多埋 2–3 条。**

埋多了显得刻意，玩家会觉得"到处是钩子"，反而不信。

## 2. 分级

| 级别 | 定义 | 不回收的后果 |
|---|---|---|
| **L1 主线级** | 世界的真相，决定结局 | 烂尾 |
| **L2 支线级** | 某个 NPC / 势力的秘密 | 遗憾，但不致命 |
| **L3 氛围级** | 只用来让世界有厚度 | 无所谓，甚至更好 |

## 4. 埋设 / 回收时间表

| 境界 | 埋 | 收 |
|---|---|---|
| 炼气 | F01、F02、F06 | — |
| 筑基 | F03 | — |
| 金丹 | F04、F08、F09 | — |
| 元婴 | F10 | F01、F04 |
| 化神 | — | F02、F03、F08 |
| 渡劫 | — | F07 |

**意义**：保证每个境界都有"新埋的"和"刚收的"，玩家永远处在"有谜题未解 + 刚解开一个"的状态。这是长线叙事的心跳。

---

## 5. 三个故意不回收的

| 谜题 | 为什么不回收 |
|---|---|
| 灵气的来源 | 世界的物理属性，不需要解释 |
| 第一个修仙者是谁 | 结局级谜题，答了就没得玩 |
| 修炼行为是自然还是人为 | 留给玩家自己想 |

**但要防止"像作者忘了"**：同一谜题至少在两个不同地方提到，让它像"世界的一部分"，而不是"挖的坑"。F06 和 F07 就是干这个的。

## 6. 烂尾风险清单

| 伏笔 | 不回收的后果 |
|---|---|
| **F01 凡人成仙** | 玩家最早接触的传说。不回收 = 耍人 |
| **F03 记忆缺口** | 玩家自己发现了缺口却不给解释 = 恐怖片没结局 |
| **F04 天劫的刻度** | 世界观的核心。不回收 = 世界观崩了 |
| F02 老者 | 会变成"又一个没下文的 NPC" |
| F05 / F08 | 可以合并回收，成本不高，建议收 |

## 7. 非伏笔的主题呈现

有些东西不是谜题，是为了让主题落地。**不要把它们当伏笔回收**，否则显得刻意。

| 场景 | 作用 |
|---|---|
| 闭关三十年，回村发现熟人都不在了 | 让"凡人是尺度"落地 |
| 你救过的人老死了，他的孙子不认识你 | 同上 |
| 你曾经住过的屋子成了别人的家 | 同上 |

这些不需要解释，只需要发生。
