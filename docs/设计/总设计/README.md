## 这个游戏是什么

> **用一具凡人的身体，在有限的一生里，走到世界的尽头。**

不是"打坐涨数字"，也不是"用命换东西"。

| 支柱 | 含义 | 反面 |
|---|---|---|
| **寿元是时钟** | 你只能让它流逝，不能花它。压力来自"错过"，不是"消耗" | 每个按钮都标价"耗寿 30 年" |
| **境界是质变** | 每境是身体改造的一个阶段，解锁新规则 | 筑基 = 炼气 × 10 |
| **斗法是磨练** | 打坐是"修"，斗法是"用"的磨练。斗法带来实战经验、心境、战利品 | 刷怪升级、斗法只是惩罚 |

---

## 核心循环

```
灵气 → [功法 × 灵根 × 心境] → 修为 → 突破（赌） → 境界 → 解锁 + 延寿上限
 ↑                                                          │
 └──────────── 时间流逝（世界在变，人在老）←─────────────────┘
```

境界内走 idle 逻辑（涨、解锁、自动化），境界间走修仙逻辑（瓶颈、准备、赌）。**每个境界是一段爽 + 一道坎。**

## 六面墙

| # | 问题 | 答案 |
|---|---|---|
| W1 | 几大境界 | 六境，身体改造的六个阶段；体系暂不区分，字段预留 |
| W2 | 延寿靠什么 | 多路径、可主动寻找，除境界外都稀有；默认不会寿元将尽 |
| W3 | 灵气丰度 | 整体稀薄（末法）+ 局部充裕（绿洲） |
| W4 | 修仙者的社会位置 | 隐匿于凡人之外，但不隔绝 |
| W5 | 是否有超验秩序 | 没有真天道，天道/天劫是前人搭的基础设施 |
| W6 | 凡人能否修仙 | 能，但是 NPC 传说：极善/极恶的品格凝结成灵根 |

## 九条决策

| # | 决定 | 可逆性 |
|---|---|---|
| D1 | 单人视角 + 宗门经营 + 道友入队 | 不可逆 |
| D2 | 战斗一次结算 + 战报演出（暂定） | 半可逆 |
| D3 | 每境界一章主线 + 事件池，弱线性 | 半可逆 |
| D4 | 飞升为通关，转世暂缓 | 半可逆 |
| D5 | 元婴分身作为后期乐趣 | 半可逆 |

| D7 | 开局完全固定：凡人、五行平庸、无背景 | 半可逆 |
| D8 | PC 横屏，1280×720 起 | 半可逆 |
| D9 | 转世暂缓，数据结构预留 | 可逆 |
