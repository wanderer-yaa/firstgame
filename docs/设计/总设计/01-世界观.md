# 01 · 世界观

> 版本：v2.0　更新：2026-10-24
> 用途：**世界是什么，为什么**。合并了原 02（结论）与 03（推理），按"墙"组织。

---

## 0. 一句话

> **修仙不是求长生，是求"走到世界的尽头"。长生只是走得到那里的前提。**

---

## 1. 三条公理

整个世界的地基。**改动任意一条，全盘重做。**

| # | 公理 | 含义 |
|---|---|---|
| **A1** | 自然是自然，人为是人为 | 世界本身没有意志、没有目的、不颁发规则 |
| **A2** | 一切"规则"都是人造物 | 天道、天劫、境界划分，都是修仙者或组织搭建、维护、争夺的基础设施 |
| **A3** | 修仙是人对自然的凌驾 | 不是顺应天道，是理解并改造它 |

三条合起来 = **祛魅的修仙**：世界是可理解的、可改造的、会腐朽的。

---

## 2. 六面墙

改变"数字"的决定不怕改，改变"结构"的决定会推翻重做。

| # | 问题 | 答案 | 改动代价 |
|---|---|---|---|
| **W1** | 几大境界？ | **六境**，是身体改造的六个阶段。**暂不区分修炼体系**，但字段预留 | 高 |
| **W2** | 延寿靠什么？ | **多路径，可主动寻找**。除境界外都稀有。默认不会寿元将尽 | 最高 |
| **W3** | 灵气稀薄还是充裕？ | **整体稀薄（末法）+ 局部充裕（绿洲）** | 中 |
| **W4** | 修仙者的社会位置？ | **隐匿于凡人之外，但不隔绝**。凡人社会是底座 | 中 |
| **W5** | 是否有超验秩序？ | **没有真天道**。天道/天劫是前人搭的基础设施 | 中 |
| **W6** | 凡人能否修仙？ | **能，但是 NPC 传说**：极善/极恶的品格会凝结成灵根 | 低 |

其余（门派名、地理、历史、人物、物品名）全是装修，可随时补——**它们占"世界观"的 90%，只占"风险"的 10%**。

## 3. 五条推论

### 3.1 没有"天意"，只有"前人"（W5）

- 天劫不是天在罚你，是某个古老组织设的关卡，或一套仍在自动运行的旧机制
- "天道反噬"其实是维护者的反制
- **附带收益**：规则会坏。年久失修的天道、被篡改的法则、失传的维护方法——免费的中后期剧情资源
- **还顺手解释了修仙界的政治形态**：规则是强者定的 → "谁最强"没有答案 → 规则必然是碎的、冲突的、地方性的。世界不是统一的天庭，而是无数势力各自立法

### 3.2 境界是身体改造的工程学（W1）

| 问题 | 物理解释 |
|---|---|
| 为什么炼气打不过筑基？ | 不是"境界压制"，是生理差异：法力容量、反应速度、恢复力 |
| 为什么突破会失败？ | 改造不可逆，中途出错就是身体崩坏 |
| 为什么每个人不一样？ | 灵根决定改造路径，通用方法会出错 |
| 为什么要闭关？ | 改造需要持续、稳定、高浓度的外部条件 |

**把玄学变成工程学，同时保住了"突破是赌"**——赌的不是天意，是你的身体撑不撑得住。

### 3.3 延寿是机会窗口，不是菜单（W2）

| 状态 | 含义 | 玩家感受 |
|---|---|---|
| 未雨绸缪 | 平时储备：灵药、人情、情报 | 我在为不知道什么时候来的事做准备 |
| 机会出现 | 事件/秘境/人物带来一次可能 | 来了 |
| **白来** | 准备了，但机会没出现 | 白忙一场 |
| **求而不得** | 机会来了，条件不够 | 差一点 |
| **错过** | 窗口期内没反应过来 | 我当时在打坐 |

三条要求：

1. 机会由事件系统产生，有触发条件、窗口期、准备要求
2. **储备必须有成本**（占空间、占时间、会腐坏），否则玩家会囤积一切
3. **机会不可预期**，所以"准备"是投资，不是计算

**叙事效果**：修士的一生就是不断准备，然后大部分准备都白费。

**代价仍不能同质**——路径多，但代价一样就只剩最优那条：

| 路径 | 代价的性质 |
|---|---|
| 境界提升 | 风险（会失败） |
| 丹药 | 边际递减（抗性） |
| 天材地宝 | 机会成本（要游历、要冒险） |
| 夺舍 | 不可逆（因果缠身、身份断裂） |

### 3.4 凡人是尺度，不是功能（W4）

灵根天生 + 仙凡相隔，很容易推出"凡人没有意义"。解法不是给凡人加功能，而是**让凡人成为参照物**：

| 层面 | 凡人的作用 |
|---|---|
| 机制 | 因果的来源、资源的来源、时间的刻度 |
| 叙事 | 你回不去了、你看着他们老死、你曾经也是他们 |

**凡人不是玩家要打交道的人，是玩家要面对的镜子。**

### 3.5 灵根是品格的物化（W6，推论）

由"凡人成仙"反推：**灵根不只是生理器官，它是"你是谁"的物化。**

| 来源 | 例子 | 性质 |
|---|---|---|
| 天生 | 五行配比 | 生理 |
| 品格 | 赤诚灵根、血肉灵根 | 德性 / 恶性的物化 |

三个推论：

1. **洗髓 = 用技术篡改"你是谁"。** 不只是改身体，是改自我。
2. **代价不只是风险。** 还有自我的磨损——你换来了天资，但不知道换掉的是什么。
3. **这是祛魅的第一步。** 玩家第一次洗髓，就已经在参与"篡改天理"。等他后来发现天道也是人造的，他不会惊讶——因为他自己干过一次。

**表现（暂定）**：洗髓后某个 NPC 认不出你；你记不清某件小事；每次洗髓，记忆缺口 +1。
**回收**：化神期，玩家自己发现缺口数量正好等于洗髓次数。（台账 F03）

## 4. W3 详解：稀薄与充裕分别带来什么

| 维度 | 稀薄（末法） | 充裕（盛世） |
|---|---|---|
| 打坐产出 | 低，增速慢 | 高，数字飞涨 |
| 洞府 / 灵脉 | 极贵，是争夺核心 | 便宜，不值一提 |
| 突破 | 难，需大量准备 | 易，不稀罕 |
| 修士数量 | 少，仙凡界限清晰 | 多，仙凡混杂 |
| 经济 | 资源稀缺，交易重要 | 资源过剩，经济失效 |
| 叙事调性 | 苍凉、珍贵 | 繁华、竞争 |
| idle 手感 | 慢热，每一分都珍贵 | 爽快，但容易腻 |
| 情绪高点 | 突破稀有 → 每次都大事 | 突破常见 → 高点失效 |

**判断：稀薄让"资源"有意义，充裕让"资源"贬值。** idle 的核心是资源转化，所以稀薄更合适——充裕会让前 30 分钟很爽，两小时后资源过剩，游戏失去张力。

**但稀薄有代价：前期太慢。** 解法是**整体稀薄 + 局部充裕**——大环境是末法，但存在"绿洲"（灵脉、洞府、秘境、福地）。

三个好处：保住稀缺感、给了奔头、**绿洲就是冲突的源头**（谁占了灵脉谁就是敌人，宗门政治与地盘争夺自然长出来）。

## 5. 敬畏 → 祛魅：两层结构

选 A2（天道是人为的），就是选了"清醒"而不是"渺小"。

| | 敬畏向 | 祛魅向 |
|---|---|---|
| 世界 | 天地不仁，人只能顺应或逆天 | 规则是人搭的，可理解、可利用、可篡改 |
| 情绪 | 壮烈、苍茫 | 清醒、智性、阴谋 |

**两者不能混，混了两头不靠。** 但也不必二选一：

| 层 | 内容 | 玩家何时看到 |
|---|---|---|
| **表层** | 天道高远、天劫可畏、因果不爽 | 炼气 → 金丹 |
| **底层** | 天道是前人搭的、会坏、可篡改 | 元婴之后 |

**玩家随境界提升，从敬畏走向祛魅——这个转变本身就是叙事回报。**

第一版只做到炼气，用不到底层，按敬畏向做 + 埋 3–5 个"不对劲"的钩子即可。

**补偿方式**：把"未知"从"神"移到"深度"——敬畏不来自不可知，来自"已知之后发现还有更多"。

## 6. 凡人成仙（W6 详情）

> **凡人可以成仙，但这是 NPC 层面的传说事件，不是玩家路径。**

```
凡人（无灵根，不能修行）
  → 品格极端（极善 / 极恶）
  → 灵根自行凝结（赤诚灵根 / 血肉灵根）
  → 拿到入场券
  → 才谈得上修行
```

**关键区分：不是"以善恶修行"，是"以品格换取门票"。** 品格不产生修为，只决定你有没有资格开始。

**命名约定**：传说级灵根 = 品格名 + 灵根（赤诚、血肉、孤绝、痴、守、杀）。每个名字都是一段传说，都能做成一条 NPC 支线。

**对玩家：第一版为零。** 只出现在 NPC 传说、事件文本、坊间流言里，系统成本为零。

**预期管理**：玩家看到传说一定会问"我能吗"。暗示能但实际不能 = 挫败；明确说不能 = 传说失去力量。**解法：让传说不可证实**——遇到一个自称凡人成仙的老者，他讲了个故事，但你无法验证真假。

**一个已知风险**：极善比极恶难做。游戏里的"善"很容易退化成"送资源"，很无聊。极善必须设计成代价高昂的选择：救人耗修为、护道得罪人、守信弃机缘。**善的重量来自它让你失去什么，不来自它让你得到什么。**
