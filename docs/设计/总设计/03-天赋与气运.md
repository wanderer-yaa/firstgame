# 03 · 天赋与气运

> 版本：v2.0　更新：2026-10-24
> 用途：灵根、天赋六维、气运与玄学的规则。世界观依据见 `01-世界观.md` §3.5。

---

## 1. 先纠错：灵根不是"越少越好"

查过之后，问题比"草率"严重——**它是反的**。

| 说法 | 出处 |
|---|---|
| 单灵根 / 五灵根 / 天灵根 | **当代网文发明**，2000 年代后才有 |
| 根器、禀赋、宿根、道基 | 佛道两家都用，指人的资质根基 |
| "灵根"一词 | 部分道书里有，但多指人的**本性 / 道性**，不是五行天赋 |

五行在丹道里讲"攒簇五行""和合四象""五行归一"——核心是**调和与归元**，不是剔除。缺一系则失衡，**"少"在五行体系里意味着"偏"和"缺"，不是"纯"**。

正确方向：**灵根不是数量，是配比。**

---

## 2. 灵根：五行配比

每个人有一组五行权重（0–5）：

| 修士 | 金 | 木 | 水 | 火 | 土 | 特征 |
|---|---|---|---|---|---|---|
| 甲 | 0 | 4 | 1 | 3 | 2 | 木火偏盛，宜火属性功法，金系难修 |
| 乙 | 2 | 2 | 2 | 2 | 2 | 五行均衡，什么都能修，什么都不突出 |
| 丙 | 5 | 0 | 0 | 0 | 0 | 金极盛，锋锐无匹，但缺木则生机弱 |

**没有绝对好坏，只有适配。**

| 影响面 | 机制 |
|---|---|
| 功法效率 | 功法有属性，配比越贴合效率越高 |
| 丹道亲和 | 炼对应属性的丹，成功率与品质更高 |
| 属性克制 | 斗法伤害倍率 |
| 突破瓶颈 | 缺的那一系会成为该境界的关卡（"土薄，金丹难结"） |

最后一条是关键：它让配比不只是数值加成，而是**具体的关卡**。玩家会记得"我土薄，卡在金丹这一关"。

**成长性**：每条权重可提升，但**总权重受"根器"限制**（根器 = 总容量，提升极慢）。所以必须选：专精一系，还是铺开均衡。

## 3. 天赋六维

| 维度 | 古典对应 | 影响 | 提升手段 |
|---|---|---|---|
| **灵根** | 根器、禀赋 | 功法效率、丹道亲和、属性克制 | 灵果、丹药、功法、洗髓 |
| **体质** | 精、形 | 元气上限、抗伤、突破承受力 | 淬体功法、药浴、天材地宝 |
| **筋脉** | 气、经脉窍穴 | 灵气吞吐速率 | 通脉、丹药、机缘 |
| **悟性** | 神之"性" | 功法领悟、突破成功率 | 读经、游历、静坐 |
| **神识** | 神之"用" | 炼丹/阵法/斗法精度 | 静坐、秘法、丹药 |
| **气运** | 命、数 | 见 §4 | **不能练，只能应** |

**前五维是"你是什么"，气运是"世界怎么看你"。**

## 4. 气运与玄学

### 4.1 一条原则：玄学给信息，不给数值

如果卜卦告诉你"成功率 73%"，它就是数值面板换了个皮，玩家会刷卦——刷到好卦再突破。玄学就死了。

**真正的玄学应该说："此卦明夷，利艰贞。"** 然后你自己判断。

| 错 | 对 |
|---|---|
| 成功率 61% | 明夷，宜守不宜进 |
| 气运 85/100 | 望气：紫气东来，然中宫有滞 |
| 命格 +12% 机缘 | 批语：孤星入命，亲缘薄 |

**玄学是决策的另一种语言，不是随机数的另一种皮肤。**

### 4.2 气运的组成

| 组成 | 性质 | 说明 |
|---|---|---|
| **命格** | 先天、固定 | 决定"哪些事容易发生在你身上" |
| **气数** | 后天、浮动 | 当前的运势走向 |

**气运不可直接提升**，只能通过行为改变：积德、杀生、夺宝、逆天、应劫。它不是一条能刷的进度条。

### 4.3 影响幅度必须小

| 影响 | 幅度 |
|---|---|
| 事件权重（好事/坏事比例） | 中 |
| 遇敌强度 | 中 |
| 机缘出现率 | 中 |
| 突破成功率 | 小（±5%） |
| NPC 初始态度 | 小 |

**幅度一旦大了，玩家就会去刷气运，玄学就变成另一种数值游戏。** 它的价值在"感觉"，不在"强度"。

### 4.4 四个层次

| 层 | 是什么 | 玩家做什么 | 频率 |
|---|---|---|---|
| **观** | 望气、看相、察星 | 被动获得信息 | 常驻 |
| **卜** | 占卦、求签 | 花时间换模糊提示 | 大事前 |
| **择** | 择日、择地、择向 | 在正确的时间/地点做正确的事 | 中频 |
| **改** | 改运、借运、夺运、避劫 | 付代价改变走向 | 低频、重代价 |

**卜卦**：消耗半日 + 材料（龟甲、蓍草），产出一句卦辞 + 方向性提示。准确率非 100%，气数低时容易得"乱卦"。

> 问：此行吉凶？
> 卦：**明夷，利艰贞。**
> 批：宜守，不宜进。若强行，伤在东南。

玩家不知道"东南"是哪个方向，直到他去了才知道——**事后恍然，事前朦胧**，这才是玄学该有的样子。

**择日**：游戏内有日历（年/月/日/时辰）。查历需要历书或师承，不查也能玩，查了更顺。**这是"知识即力量"，不是"数值即力量"。**

### 4.5 劫：让玄学站得住的关键

> **劫不是随机事件，是你过去所有选择的总账。**

| 项 | 设计 |
|---|---|
| 何时 | 每个大境界一次 |
| 形式 | 由因果 + 气数决定，**不是随机** |
| 能否避开 | 不能，只能应 |
| 结果 | 应劫的方式决定成败 |

玩家回头看会发现"这一劫是我三十年前那件事招来的"——**玄学因此有了可推敲性：它不是掷骰子，是延迟结算。**

### 4.6 命格：叙事种子，不是数值加成

开局固定，只给名字和一句批语，不给数字。

| 命格 | 倾向 |
|---|---|
| 孤星 | 亲近之人易遭不测 |
| 富贵 | 财帛易得，但易招觊觎 |
| 早慧 | 悟性增长快，但心境易损 |
| 迟成 | 前期慢，后期厚 |

**玩家玩到中后期才明白自己的命格是什么意思——这个"明白"本身就是回报。** 开局就写"+12% 机缘"的话，它只是个 buff。

## 5. 提升天赋不靠按钮

| 手段 | 特点 | 代价 |
|---|---|---|
| **灵果** | 一次性、稀有，提升某一系 | 有产地、要寻访、会被人抢 |
| **丹药** | 一次性 | 材料 + 炼丹 + 抗性 |
| **功法** | 持续、缓慢 | 占用主修位 |
| **洗髓** | 一次性、极险，重排配比 | 长期闭关 + 失败风险（**不扣寿元**） |
| **机缘** | 顿悟、传承 | 不可控 |

### 5.1 洗髓

**不是"用寿命换天赋"，是"用风险换天赋"。**

| 项 | 内容 |
|---|---|
| 是什么 | 重塑肉身，把五行配比重排 |
| 形式 | 一次长期闭关（耗时数年），期间不能做别的 |
| 成功 | 配比更优（按玩家预先设定的方向重排） |
| 失败 | 经脉受损（产出减半一段时间）+ 可能跌落小境界 |
| 不消耗 | **寿元**（只消耗时间，时间自然流逝） |

它不再是按钮，是**有准备、有风险、有代价的行动**，而且只是五种手段之一。
