## 0. 最重要的一条：我把"时间流逝"做成了"资源消耗"

你的第一条不是一条意见，是**框架错误**。我确实把"寿元是资源"当成了整个设计的地基，于是：

- 洗髓折寿 → 用命换天赋
- 突破失败折寿 → 用命换风险
- 闭关耗寿 → 用命换修为
- 甚至连"多路径延寿"都变成了"四条命换命的路"

**这不是沉浸感，这是会计报表。** 玩家每点一个按钮都在算"这一下花了我几年"，那不是修仙，是理财。

### 修正后的模型

| | 旧（错） | 新 |
|---|---|---|
| 寿元是什么 | 货币 | **时钟的刻度** |
| 何时变化 | 玩家做选择时 | **行动执行后，时间流逝** |
| 压力来源 | "我还剩多少可以花" | **"我做的这件事，会让我错过什么"** |
| 玩家感受 | 精算 | 纠结 |

**三条规则**

1. **思考时世界静止。** 玩家在菜单前犹豫多久，时间都不走。
2. **行动有耗时，执行后时间前进。** 打坐一日、游历三月、闭关十年。
3. **时间前进 → 世界变化。** 人物变老、事件窗口关闭、地貌变迁、故人去世。

**寿元只有两种减少方式**

| 方式 | 说明 |
|---|---|
| 时间流逝 | 唯一途径。你活了多久，就少了多少 |
| 上限被损伤 | 突破失败、重伤、根基受损——钟被砸短了，不是被花掉了 |

**玩家永远不能"花寿元"。** 这是新旧模型的分水岭。

### 这条改动的连锁

| 旧设定 | 新设定 |
|---|---|
| 洗髓折寿 10–30 年 | 洗髓有风险（失败则经脉受损），但不扣寿元 |
| 突破失败折寿 20–50 年 | 突破失败 = 修为倒退 + 重伤卧床（时间流逝）+ 根基受损（上限降低） |
| 闭关消耗寿元 | 闭关消耗时间，时间自然让寿元减少 |
| 寿元是预算，要分配 | 寿元是刻度，要留意 |

**压力从"资源消耗"变成"机会成本"**——这才是沉浸感。你闭关五十年出来，发现山下换了三个朝代，仇人已经老死了，那场百年一遇的秘境早在三十年前就开过了。

### B1 展开：斗法的新定位

旧：斗法是代价，不是玩法。
新：**斗法是成长的验证，不是成长的替代。**

意思是：斗法不产生修为（不能刷怪升级），但它验证你的 build 是否成立。你练了三十年的剑，第一次出鞘——这个瞬间必须有分量。所以战斗要做得**少而重**，不是多而轻。

### B4 展开：修为条的表现

你说"带数字的修为条太出戏"，我同意，而且这能推出一条 UI 总则：

> **默认沉浸，按需精确。**

| 层 | 表现 | 何时出现 |
|---|---|---|
| 默认层 | 光晕浓度、呼吸节奏、气感 | 一直在 |
| 提示层 | 悬停才显示精确数值 | 鼠标停留 |
| 详情层 | 完整数据面板 | 主动打开 |

修为不写"412 / 900"，写"气机充盈，尚差一线"。玩家想看数字就悬停。这既是沉浸，也是 PC 交互的自然用法（AE2 终端的心智模型本来就是悬停）。

## 3. C 部分逐条

### C1 境界按修炼体系区分

**采纳，但需要拆开两个概念：**

| 概念     | 是什么      | 是否共用          |
| ------ | -------- | ------------- |
| **境界** | 身体改造的阶段  | **所有体系共用同一套** |
| **体系** | 改造的路径与方式 | 各有各的          |

体修、血修、气道、剑修，走的是同一条境界阶梯，但每一阶的改造部位、能力、代价都不同。这样"可兼修"才有意义——兼修是同时走两条改造路径，代价是资源分散。

详细提案见 `05-修炼体系与天赋.md` §5。

### C2 延寿：主动寻找 + 稀有

**采纳，并修正我的"机会窗口"设定。**

| | 旧 | 新 |
|---|---|---|
| 获取方式 | 只能等机会 | **可以主动寻找**（打听、寻访、求药） |
| 频率 | 随机 | 稀有，但可预期地稀有 |
| 前提 | — | 不铤而走险 + 运气不极差 → 不会寿元将尽 |

"稀有"本身是世界观的表达：延寿之物稀少，所以**拥有它的人/地方就有底蕴**。这给叙事提供了反差——一个破落小派藏着一株万年灵芝，比"人人都能买延寿丹"有意思得多。

### C3 灵气稀薄 vs 充裕，分别带来什么

这是你问得最实的一条，我逐项列：

| 维度 | 稀薄（末法） | 充裕（盛世） |
|---|---|---|
| 打坐产出 | 低，增速慢 | 高，数字飞涨 |
| 洞府 / 灵脉 | 极贵，是争夺核心 | 便宜，不值一提 |
| 突破 | 难，需要大量准备 | 易，不稀罕 |
| 修士数量 | 少，仙凡界限清晰 | 多，仙凡混杂 |
| 经济 | 资源稀缺，交易重要 | 资源过剩，经济失效 |
| 叙事调性 | 苍凉、珍贵、末法之悲 | 繁华、竞争、大宗门林立 |
| idle 手感 | 慢热，每一分都珍贵 | 爽快，但容易腻 |
| 情绪高点 | 突破稀有 → 每次都是大事 | 突破常见 → 情绪高点失效 |

**关键判断：稀薄让"资源"有意义，充裕让"资源"贬值。**

idle 游戏的核心是资源转化，所以**稀薄更合适**。充裕会让前 30 分钟很爽，但两小时后所有资源都过剩，游戏失去张力。

**但稀薄有个代价**：前期太慢，玩家会流失。

**解法：整体稀薄 + 局部充裕。**

世界大环境是末法，但存在"绿洲"——灵脉、洞府、秘境、福地。玩家的一生就是在寻找和占据这些绿洲。

这个结构有三个好处：

1. 保住了稀缺感（大环境）
2. 给了奔头（绿洲可寻）
3. **绿洲就是冲突的源头**——谁占了灵脉，谁就是敌人。宗门政治、地盘争夺、杀人夺宝，全部自然长出来
