### 本轮关键设计修订

1. **寿元从"倒计时"改为"预算模型"**：自然衰老 0.002 年/秒（沿用基准图数值）+ 事件性大额消耗（闭关 10–50 年、重伤 1–5 年、突破失败 20–50 年），日常打坐不耗。理由：线性倒计时要么没压力（10h 只掉 72 年），要么 3 小时老死。
2. **战斗定位为"事件的一种"**：开战前是唯一决策点（战/避/送礼/用物/请援），之后 3–6 回合自动结算出文字战报。修为≠战力，战力来自功法/法器/丹药/阵法，允许越阶。越阶用乘数（每级 ×2.2）而非加法。打赢也要付账（重伤=疗伤时间=寿元）。
3. **数值规模锁死 1e6**，修为条恒为 0–10000 量级，避免 UI 出现 1.24e15 破坏修仙感。
4. 炼气期数值基线：需求比率 2.1，裸算 80 分钟，算上加成目标 45–60 分钟。

## 第二轮回复（v0.2）

用户拍板：PC 横屏 / 寿元确认为核心压力源 / 开局 roll「任意配置难度相同、缺的都能补全」。并明确要求：**设计师要有批判性，不要草率认同**。

### 我提出的反驳（用户诉求 → 设计矛盾 → 解法）

1. **D7 自相矛盾**：寿元预算模型下，补全要花寿元 → 天赋差的人补得更多 → 更紧 → 难度必然不同。"难度相同"与"都能补全"互斥。已改为可操作定义：**期望通关时间相差 ≤15%，且无无解配置；差异在路径不在终点**。
2. **严格"难度相同"会杀死 roll**：选什么都一样 → 仪式感崩塌。改用**曲线交叉**：天灵根前期领先（×2.0）但寿元上限 ×0.75（天妒）、心魔 ×1.5；杂灵根前期 ×0.8 但寿元上限 ×1.15、突破成功率 +15%，后期反超。终点对齐、体验相反。
3. **提出核心原则**：**可补的是资源，不可补的是身份**。灵根/功法/体质可补（代价是寿元），主修功法/道心/因果不可逆。这样既满足"都能补全"，又保住"我是谁"。
4. **纯随机会导致重开到满意为止** → 建议默认"随机 3 选 1"（Q5 待确认）。
5. **最危险的技术洞**：突破必败 + 单机手动存档 = 玩家 SL 到成功，"突破必须失败"铁律归零。已写入技术铁律 #6：判定用一次性种子锁定并即时落盘，读档不可重算。
6. **寿元压力的颗粒度**：防止 Dead Rising 式焦虑——不做每秒跳动的倒计时，压力集中在"闭关/突破/疗伤"这类大决策，剩余 <10% 才变色。
7. **PC 横屏的具体含义**（不只是分辨率）：1280×720 起、全键盘可操作（1–9 切活动 / Space 暂停 / Tab 切面板）、悬停即详情、三态窗口、启动时必须给离线回执。

## 第三轮（v0.3）：开局从 roll 改为出身

用户提出：不 roll 了，直接给不同初始难度供选择；转世重修可获得更好的初始配置。

### 我的批判（三点）

1. **"难度选项"会给核心机制装开关**：若难度档调的是规则（寿元上限/突破率/敌人强度），选"简单"就等于关掉 D6，用户刚定的核心压力源被自己一键跳过。
2. **难度选择界面存在"中间选项收敛"**：玩家避开"简单"（羞耻）也避开"困难"（怕卡关），三档实际只用一档，等于给了个假自由。
3. **转世给更强配置会毁掉首周目**：玩家一旦知道第一世是过渡就不认真玩；且最优策略变成速通滚雪球，每一世都成跳板。这与 D7「难度对齐」也冲突。

### 解法

- **难度 → 出身**（世家子弟/门派弟子/散修/弃婴），选的是人生不是难度条。
- **关键分界线：难度可选，天赋不可选。** 出身可选（决定起点资源、社会位置、灵根概率分布），灵根仍随机（宿命感保留）。
- **难度只调起跑线，不调规则**：世家子弟寿元上限也是 120 年、突破照样会败。这是 D7 与 D6 共存的唯一方式。
- **天灵根只对散修开放**（方差最大），世家子弟上限上品——想要天资就得没有靠山。
- **转世解锁出身，不给数值**：第一世 2 个出身 → 第二世 4 个 → 第三世「仙帝残魂」。道基只给 +5%~8% 永久效率，不足以碾压。

## 第四轮（v0.4）：起点固定 + 事件延后 + 单结局

用户拍板：转世暂不考虑；开局固定最差天赋、不选难度（"idle 每个玩家起点应该相同"）；事件原本没考虑，想先搭修炼流程，问能否后续加；结局先做一个。

### 我的判断与修订

1. **固定起点是对的，但天赋必须从"常数"变成"成长线"**——起点固定后天赋在第一周目就是死数据。改为：开局五灵根（×0.80 / 寿元 ×1.15 / 突破 +15%），可花寿元逐级洗髓到四→三→双→天（折寿 10/15/25/40 年，累计 90 年）。于是天赋成了寿元的第二个出口，玩家要在"花命补天赋"和"花命冲境界"之间选——原本描述随机结果的"曲线交叉"现在描述玩家自己的选择。
2. **洗髓四条约束**：只能逐级、折寿不可逆、有虚弱期、会打断当前活动。否则它会退化成一条必点的升级线。
3. **身份不是选的，是挣的**：宗门/人脉改为游戏内事件获得（中期被门派看上或被拒），而不是开局选项。更符合"从山脚爬上去"。
4. **事件可以后加，但三个接口必须现在埋**：世界状态 flags、统一条件求值器、活动状态机（可 interrupt/resume）。外加五个触发点空实现（活动完成/突破/进新地点/每月/寿元阈值）。成本≈0，省一次重构。
5. **批判：事件不该"推进"修炼，该"打断"修炼**。若事件只是给资源，就退化成随机宝箱，破坏 idle 节奏。事件要低频（10–20 分钟一次）、高影响、有代价。
6. **单结局可以，但必须做"通关回顾"**（寿元账本 / 因果 / 关键人物结局），否则飞升后就是黑屏。结局走 endings.json 表，第一版一条。

## 第五轮（v0.5 + 新文档）：世界精神内核

用户提出世界观主张（并批评我不该把埋雷留到最后才说，要求明确差分目标）。核心主张：自然/人为二分；世界无意志，天道天劫是人为的；境界是身体改造阶段；延寿是"路上的坎"而非目的；多手段达成同一结果；凡人不应因仙凡相隔而失去意义。

### 我的批判与修订

1. **"延寿是坎"不是补充，是推翻动机链**：原本"为长生→突破→延寿"，改为"为走到世界尽头→境界是通行证→寿元是截止日期"。寿元从**目标**降为**约束**。理由：为不死而修炼的主角是功利的，为看世界尽头的是浪漫的；压力从"我怕死"变成"我来不及"，更耐玩。半可逆改动，越晚越贵。
2. **"多手段达成同一结果"是陷阱**：五条路若代价同质，只剩一条最优解。改为"路径要多，代价不能同质"（境界=风险 / 丹药=边际递减 / 天材地宝=机会成本 / 夺舍=不可逆）。
3. **A2（天道人为）会消解敬畏**：修仙最动人的是"天地不仁"。天道若是人做的，玩家面对的不再是宇宙而是官僚。必须选边不能混（敬畏向 vs 祛魅向）。建议选祛魅，补偿方式是"把未知从神移到深度"——敬畏不来自不可知，来自"已知之后发现还有更多"。
4. **境界=身体改造很好，但会杀死"赌"**：需补物理解释——改造不可逆，中途出错=身体崩坏；灵根决定路径，通用方法会出错；闭关=需要持续高浓度外部条件。这样赌的是身体不是天意。
5. **凡人是尺度不是功能**：不是给凡人加功能，而是让凡人成为参照物（因果来源、资源来源、时间刻度；回不去、看他们老死、曾经也是他们）。
6. **三个答不上来的问题（灵气来源/修炼是自然还是人为/第一个修仙者）建议留白**，空白比错误答案好。
7. **A2 的免费收益**：规则是强者定的 → 无唯一最强 → 规则必然碎而地方化 → 世界是无数势力各自立法，白得政治质感。

## 第七轮：W6 定案（凡人成仙 = 极端事件）

用户决定：凡人可以成仙，但这是最极端事件，唯有**极善或极恶之人的毅力**才可能成功。

### 我的判断与衍生约束

1. **这个定位保住了 D7**：灵根仍是效率而非资格，所以"五灵根开局"依然成立；同时凡人有尊严（"几乎不能"而非"永远不能"），且白送一个隐藏高难度模式（行为触发，不是菜单）。
2. **"人性"成为第三种资源**：不只可以用寿元换道，还可以用"人"换道。
3. **必须现在定的衍生问题：因果是强度轴，不是善恶轴**。极善极恶都能成仙 → 大道无情；但两条路代价必须不同质（极善慢苦但天劫轻有人助；极恶快狠但天劫重众叛亲离）。一句话原则：**游戏不审判玩家的道德，但世界会回应**——极恶者成仙时没有人来送他。
4. **因果不可见但可感**：显示数值玩家就会刷。只给称号/声望/NPC 态度，永远不显示"还差多少"。
5. **道德锁**：极善作恶一次前功尽弃，极恶心软一次前功尽弃。一旦开始不可回头。
6. **与"境界=身体改造"的兼容**：灵根是改造身体的接口，无灵根者只能"绕过接口，用心性撬动身体"，极危险但理论可行。两条路到同一套境界，走法不同。
7. **已知风险：极善比极恶难做**。游戏里的善容易退化成"送资源"，必须设计成代价高昂的选择（救人耗修为、护道得罪人、守信弃机缘）。善的重量来自失去什么，不来自得到什么。
8. 对 M0 零影响（因果属 P2），但约束已记入 `01-系统拆分.md` 的 Karma 条目。

## 第八轮：纠正误读（W6 重写）

用户纠正两点：

1. **凡人成仙是 NPC 案例**，用于展现世界观与加深叙事；玩家不走这条路（隐藏"凡人开局"以后可做，现在不考虑）。
2. **不是"以善恶修行"，是"以极善/极恶的行为品格获取成仙的入场券"**，如赤诚灵根、血肉灵根。

### 我的错误与修正

把"入场券"读成了"修行路径"，连带推出"因果必须是强度轴"——**已撤销**。因果仍是普通带符号的善恶记录，不承载成仙路径。"极端"是阈值事件，不是刻度。

### 正确的因果链

凡人（无灵根）→ 品格极端 → 灵根自行凝结（赤诚/血肉）→ 获得修行入场券 → 才谈得上成仙。灵根是门票，不是功法。

### 由此衍生的新推论（已写入文档）

1. **灵根有两个来源**：天生（五行）与品格（赤诚/血肉）。这主张"灵根是品格的物化"，不只是生理产物。
2. **给洗髓补了理论依据**：既然灵根能被品格长出来，它本来就不是不可变的。
3. **命名约定可复用**：传说级灵根 = 品格名 + 灵根（赤诚/血肉/孤绝/痴/守/杀），每个名字都能做成一条 NPC 支线。

### 3. 玄学系统（核心提案）

**总原则：玄学给信息，不给数值。** 卜卦若告诉你"成功率 73%"，就是数值面板的另一种包装，玩家会刷卦。真正的玄学应说"此卦明夷，利艰贞"，然后玩家自己判断。

- **气运组成**：命格（先天固定）+ 气数（后天浮动）。**不可直接提升**，只能通过行为改变（积德/杀生/夺宝/逆天/应劫）
- **影响幅度必须小**（突破成功率仅 ±5%），否则玩家会刷气运，玄学变成另一种数值游戏
- **四个层次**：观（望气，被动）/ 卜（占卦，大事前）/ 择（择日择地，中频）/ 改（改运借运，低频重代价）
- **卜卦**：消耗半日+材料，产出一句卦辞+方向性提示，准确率非 100%，气数低得乱卦。卦辞必须模糊——"事后恍然，事前朦胧"
- **劫**（最重要）：**不是随机事件，是过去所有选择的总账**。每大境界一次，形式由因果+气数决定，不可避只能应。这让玄学有了可推敲性——不是掷骰子，是延迟结算
- **命格**：只给名字+批语，不给数值。玩家中后期才明白自己的命格，这个"明白"本身就是回报
- 天赋扩为**六维**：灵根/体质/筋脉/悟性/神识/气运。前五维是"你是什么"，气运是"世界怎么看你"

### M0 的唯一验证目标

> **玩家会不会在"要不要现在突破"这一刻犹豫。**

不是验证功能多少，是验证数值能否产生一次真实的纠结。配套三个子问题：到三层用时 4–6 分钟；失败后想再试而非想关；玩家能用"年"说出玩了多久。

### 关键设计决定

1. **1 现实秒 = 1 游戏日**。15 分钟 ≈ 2.5 年，占寿元 2% → 前期无压力（符合"默认不会寿元将尽"）。
2. **离线不推进游戏日、不消耗寿元**，只结算资源（50% 效率、上限 8 小时）。理由：1 秒=1 日的速率下，离线 8 小时 = 28800 日 = 79 年，一觉醒来就老死。离线与在线必须脱钩，这是 idle 通用做法。M0 的简化，正式版若要做"世界在你离开时也变"，需单独标定速率。
3. **三层是一道坎**（炼气分三段，三/六/九层各一坎）。既符合修仙文惯例，也解释了 M0 为何以三层→四层为终点。
4. **一→二、二→三是自动升层，不需要按钮**。只有"坎"才需要玩家决策——这让 M0 只有一次真正的选择点，测试目标清晰。
5. **突破失败不扣寿元，只损伤上限（−10 年）**。钟被砸短，不是被拿走一截。
6. **修为条默认不显示数字**（"默认沉浸，按需精确"的第一个实践点），悬停才显示。
7. 切换活动时进度保留 50%，防止无脑切换。

## 第十七轮：修复共享记忆的角色污染

用户发现：`MEMORY.md` 是本项目**所有 agent 共享**的记忆，我却在里面写了"## 我的角色：设计"。后续添加制作 agent 时会串角色。

### 问题定性

不只是措辞问题，是**结构问题**：共享记忆里出现第一人称，等于让每个读它的 agent 都以为自己是设计。

### 修复方案（三层分离）

| 层                  | 放什么                                       | 谁维护    |
| ------------------ | ----------------------------------------- | ------ |
| 共享记忆 `MEMORY.md`   | **只放所有角色都该知道的项目事实** + 一张中性的三方职责表（不带"我是谁"） | 只有设计能改 |
| `docs/协作约定.md`（新建） | 完整角色职责、交接规则、冲突处理、新建 agent 的实操步骤           | 设计     |
| 各 agent 的配置/提示词    | 角色专属的工作方式                                 | 用户配置时写 |

### 关键设计

- 共享记忆里写"**你属于哪个角色，由你的 agent 配置决定**"——把身份判定交给配置，不交给记忆
- 职责表用第三人称，任何 agent 读都不会误解
- 记忆写入约定：MEMORY.md 只有设计改（防并发覆盖）；制作/审查的记录进 `docs/审查记录/`
- 每日日志明确定性为"历史记录，不是当前事实"

### 新建 agent 的三步（写进协作约定 §6）

1. 提示词写明角色："你是本项目的制作 agent，先读 协作约定.md 与 MEMORY.md"
2. 告诉它当前任务
3. 不要多给别的角色职责（多给一句"顺便看看设计有没有问题"，边界就糊了）
